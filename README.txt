Rupa Cafe Complete Pro Website

Features:
- Beautiful frontend restaurant website
- Admin login
- Add / edit / delete food items
- Upload food images from admin panel
- Available / Not Available toggle
- Unavailable items show on frontend but cannot be ordered
- Customer cart and order placement
- Customer orders visible in admin panel
- Order status update: Pending / Preparing / Completed / Cancelled
- Website settings editor
- JSON file storage

Run:
run this command in CMD as administrator
"winget install OpenJS.NodeJS.LTS"

1. Extract ZIP
2. Open CMD in extracted folder 
3. Run: npm install
4. Run: npm start

Open:
Frontend: http://localhost:3000
Admin: http://localhost:3000/admin/login.html
